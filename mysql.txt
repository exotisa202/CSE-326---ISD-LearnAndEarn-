Local MySQL development notes
=============================

Use a dedicated local development database, not a shared or production database.
Create a database named learnandearn and a dedicated least-privilege user using
MySQL's administrative tools. Choose your own password; never commit it.

Configure the application using environment variables:
  DB_URL=jdbc:mysql://localhost:3306/learnandearn
  DB_USER=learnandearn
  DB_PASSWORD=<your-local-password>

Run: sh ./mvnw spring-boot:run

For a database-free synthetic demo, use sh ./run.sh instead.
Historical hosted credentials have been removed from these notes. Original Git
history is retained. See README.md for configuration and safety limitations.
